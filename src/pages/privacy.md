本隐私政策说明您在访问理科迷（LKM）网站（以下简称"本网站"）时的信息处理方式。

本网站是纯静态站点，托管于 GitHub Pages，不运行任何服务器端代码，不提供真实账户系统。请在使用前仔细阅读本政策。

## 信息收集与存储

### 本地浏览器存储

本网站的部分功能（如编辑器文档、社区板块的演示内容、用户偏好设置）使用浏览器的 localStorage 将数据存储在您的设备本地。这些数据不经过任何服务器传输，仅保留在您的浏览器中。

您可以随时通过浏览器设置清除这些数据。

### 我们不会收集的信息

本网站不收集、不存储、不处理以下信息：

- 支付信息

### 自动收集的使用数据

由于本网站托管在 GitHub Pages 上，GitHub 可能会收集访问日志（包括 IP 地址、User-Agent 等）以提供服务。相关数据处理请参见 [GitHub 隐私声明](https://docs.github.com/cn/site-policy/privacy-policies/github-privacy-statement)。

## AI 功能的数据处理

本网站提供可选的 AI 辅助功能（如 AI 写作助手）。使用这些功能时请注意：

- **API Key**：AI 功能所需的 API Key 仅在页面运行时保存在浏览器内存中，不会写入 localStorage 或其他持久化存储，也不会发送到我们的任何服务器。
- **数据传输**：启用 AI 功能后，您输入给 AI 的提示词和编辑器内容会**直接**从您的浏览器发送到您选择的第三方 AI 服务商（如 OpenAI、Anthropic 等）。本网站不在中间环节拦截、存储或处理这些数据。
- **用户责任**：使用 AI 功能即表示您同意遵守相应第三方服务商的服务条款和隐私政策。我们建议您在使用前查阅相关第三方的隐私政策。

## 社区与账户功能

本网站中的社区、账户、通知和后台管理页面均为前端演示功能，使用 mock 数据和 localStorage 模拟。您在这些页面中输入的任何信息仅保存在您的浏览器本地，不会传输到任何服务器。

本网站不提供：

- 真实的用户注册或登录
- 服务器端数据持久化
- 跨设备数据同步

## 第三方链接

本网站可能包含指向第三方网站的链接。我们不对第三方网站的内容、隐私政策或数据处理实践负责。建议您在访问第三方网站时阅读其隐私政策。

## 儿童隐私

我们的服务不面向儿童。我们不会故意收集任何年龄段的个人信息，因为我们不运行服务器端数据收集机制。

## 本隐私政策的变更

我们可能会更新本隐私政策。更新后的版本将发布在此页面，并在顶部注明"最后更新"日期。建议您定期查看本页面以了解变更。
