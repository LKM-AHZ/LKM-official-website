本政策说明理科迷（LKM）网站及社区服务在提供账号、内容、互动、文件和管理功能时如何处理信息。

> 本页面已经按当前 SSR 前端和 FastAPI 后端的实际能力更新，但运营主体、保存期限、未成年人规则、
> 适用法律和用户权利流程仍须由运营方及专业法务最终确认。上线前不得删除文末待确认清单。

## 适用范围

本政策适用于 LKM 官方网站、社区页面、账号系统、文件库、博客、通知、积分、项目、问答及相关后台服务。跳转到第三方网站或使用第三方服务时，还适用该第三方的政策。

## 我们处理的信息

### 账号与认证信息

- 用户名、邮箱、手机号及账号状态；
- 密码的安全哈希，不保存可读明文密码；
- 登录、刷新、登出、账号恢复、二次验证和安全事件记录；
- GitHub OAuth 返回的必要账号标识；
- Passkey/WebAuthn 凭据的公钥和元数据。指纹、面容或设备 PIN 由设备和操作系统验证，服务端不接收生物特征原始数据。

### 用户提交和互动信息

- 个人资料、头像、联系方式及公开展示设置；
- 帖子、评论、问答、专栏、博客、项目、文件及其审核状态；
- 关注、收藏、浏览、积分、成就、通知和举报记录；
- 与上传、下载和 Git 博客同步有关的文件元数据及操作记录。

用户主动公开的内容可能被其他用户查看、引用或保存。发布前请避免包含身份证件、住址、私人联系方式或他人的敏感信息。

### 设备、日志与安全信息

为保障服务、排查故障和防止滥用，服务器和网关可能处理 IP 地址、请求时间、User-Agent、请求路径、状态码、错误信息、限流和审计记录。启用 Sentry、OpenTelemetry 或分析组件时，相关错误和性能数据会按部署配置发送到对应服务。

## 浏览器本地数据和 Cookie

- 前台会话会将必要的 token 和用户状态保存在浏览器 `localStorage`（键 `lkm-auth-store`）。退出登录会清理该记录。
- 主题、色相、侧栏状态等界面偏好可能保存在 `localStorage`。
- 语言偏好使用 `lkm-locale` Cookie。
- 管理后台使用由服务端设置的 HttpOnly Cookie；生产环境要求 HTTPS 和 Secure 属性。

不要在公共设备上保持登录。可通过退出登录和浏览器设置清理本地数据；清除后可能需要重新认证。

## 信息用途

我们仅为以下目的处理信息：

1. 创建和维护账号，完成登录、恢复与安全验证；
2. 提供社区内容、互动、文件、通知和个性化功能；
3. 执行审核、权限、反滥用、限流和安全响应；
4. 排查故障、统计服务质量和改进产品；
5. 履行法律义务并处理侵权、投诉或争议。

## 第三方与受托服务

根据部署配置，服务可能使用 GitHub OAuth、邮件或短信发送服务、S3 兼容对象存储、错误监控、可观测性或 AI 服务。只有在功能所需范围内才向相应服务传输数据。

使用 AI 功能前，界面应说明数据接收方。用户输入、对话上下文或选定内容可能发送给所选 AI 服务商；请勿提交秘密、未公开研究、他人个人信息或无权共享的材料。

我们不会因为本文而承诺出售或不出售数据；该事项必须由运营方在法务审核后给出明确政策。

## 保存与安全

不同数据的保存期限取决于账号状态、内容用途、安全审计、备份和法律要求。当前代码库没有一份覆盖全部数据类型的统一期限表，运营方须在上线前补齐。

项目采用密码哈希、权限控制、HTTPS、HttpOnly 管理 Cookie、限流、审计和备份等措施，但任何系统都无法保证绝对安全。发现疑似泄露、账号异常或漏洞时，请不要公开敏感细节，应通过联系邮箱报告。

## 用户选择与权利

在产品能力和适用法律允许的范围内，用户可请求访问、更正、导出或删除账号及相关信息，也可撤回可选功能的授权。具体身份核验、处理时限、例外和申诉流程仍需运营及法务确认。

删除账号不一定立即移除备份、安全审计记录、依法需保留的信息，或已被其他用户合法引用的公开内容。

## 未成年人

社区可能被未成年人使用。年龄门槛、监护人同意、内容保护和未成年人请求流程尚需运营方依据实际服务地区及适用法律确认。未完成该确认前，不应在页面中宣称服务“不面向儿童”或默认已取得监护人同意。

## 政策变更

重大变更将更新本页日期，并通过适当方式通知。变更生效前继续使用所需的额外同意，应由运营和法务按变更性质确定。
