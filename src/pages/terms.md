## 账号与安全

- 注册信息应真实、合法且不侵犯他人权益。
- 用户应妥善保管密码、验证码、恢复码、Passkey 和访问设备，不得共享账号或代替他人完成安全验证。
- 发现未经授权的登录、凭证泄露或账号异常时，应立即修改凭证并联系维护者。
- 账号权限、认证状态、积分或管理员身份不得通过漏洞、自动化滥用或伪造请求获取。

运营方可为安全、审核、维护或法律要求限制账号功能，但具体通知、申诉和恢复流程仍需正式确认。

## 用户内容

用户可能提交帖子、评论、问答、博客、项目、头像、文件及其他材料。用户应保证：

1. 对提交内容拥有必要权利或授权；
2. 内容不违法、不侵犯隐私、著作权、商标或其他权利；
3. 不上传恶意程序、窃取凭证的内容或故意破坏服务的文件；
4. 不冒充他人，不发布欺诈、骚扰、仇恨、威胁或非法交易内容；
5. 不利用自动化手段绕过限流、审核、权限或安全控制。

为托管、展示、备份、审核和技术处理用户内容，运营方需要获得必要的非独占许可。许可范围、地域、期限以及账号删除后的处理必须由正式条款进一步明确。

## 社区管理

内容可能经过自动或人工审核。违反规则的内容可能被限制展示、退回、删除或保留为安全证据。管理员操作应受权限、审计和申诉机制约束；具体社区规范与处罚梯度应另行发布。

紧急安全问题、侵权通知或包含个人敏感信息的举报不应在公开讨论区展开。

## 文件与 Git 博客

- 上传者应在发布前检查文件内容、格式、许可证和恶意代码风险。
- 文件进入审核、下载或对象存储流程，不代表运营方对其正确性、安全性或权利状态作出保证。
- Git 博客功能可能记录提交历史；已经推送的秘密即使从最新版本删除，也可能仍存在于历史中。
- 不得在仓库、文章或附件中提交密码、token、私钥、验证码或未授权的个人数据。

## 第三方服务与 AI

GitHub OAuth、对象存储、消息发送、监控、外部链接和 AI 能力可能由第三方提供。使用这些功能时还需遵守第三方条款。

AI 输出可能不准确、不完整或带有偏差，不应直接作为医疗、法律、财务、安全或其他高风险决定的唯一依据。用户应核实输出，并确保有权向 AI 服务商提供输入材料。

## 知识产权

网站软件按仓库标明的开源许可证提供；站点文字、图片、商标和用户内容可能适用不同许可证或权利声明。开源代码许可证不自动授予品牌、内容或用户材料的使用权。

如果认为内容侵犯权利，请在通知中提供作品或权利说明、涉嫌侵权位置、联系方式和善意声明。具体通知与反通知流程仍需法务确认。

## 服务变更与可用性

服务可能因维护、安全事件、依赖故障或功能调整而中断。运营方应对重大变更和计划性停机进行合理通知，但不保证服务永久、无错误或适合所有用途。

用户应自行保留重要内容副本。备份和恢复措施用于服务连续性，不等同于面向每位用户的无限期存档承诺。

## 免责声明与责任限制

服务按当前可用状态提供。适用法律不允许排除的责任不受本条影响；其他保证、责任上限、间接损失和不可抗力条款必须由运营方结合实际主体与司法辖区经法务确认后生效。
